# Data

Put the two IFC files of the challenges in this folder, with these names:

| File | What it is |
|---|---|
| `MiniBIM.ifc` | MiniBIM 3.1 (VORM), georeferenced with the IFC Georeferencer of buildingSMART Netherlands. The same file we used in BIM A+2, "Anatomy of an IfcWall". |
| `CP1_AI_model.ifc` | Complexo Pedagógico I (UMinho), an IFC model generated with AI. |

The files are shared on the course page. They are not stored in this repository.
